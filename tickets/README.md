# Service desk practice

How I handle a ticket:
1. **Read and classify:** incident or request, priority (impact x urgency), category (access, network, storage, service, other).
2. **Reproduce and collect facts:** host, user, time, exact error, what changed.
3. **Use the knowledge base** first; follow the runbook.
4. **Resolve or escalate** with a clear handover: what was checked, results, hypothesis.
5. **Close with a short summary** the user understands; update the KB if the case was new.

See [sample-tickets.md](sample-tickets.md) for worked examples.
