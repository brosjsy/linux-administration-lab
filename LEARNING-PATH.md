# Learning path: from beginner to professional

| Level | Goal | Modules | Scenarios | Proof of skill |
|-------|------|---------|-----------|----------------|
| **L1 Beginner** | Use the command line confidently | 01 to 05, 11 | 1 to 10 | Install a service, create users, schedule a job |
| **L2 Junior admin / on-duty engineer** | Handle tickets and alerts alone | 06 to 10, 12, 15, 16, runbooks, tickets, kb | 11 to 20 | Close sample tickets with runbooks, write a KB article |
| **L3 Admin** | Build and run services, automate | 13, 14, 17, 19, 20, 21, 22 | 21 to 30 | Run `ansible/site.yml` on both VMs, DNS + DHCP + Samba working |
| **L4 Professional** | Secure, scale and recover | 18, 23, 24, 25 | 31 to 40 | Hardening score before/after, recovery drills, monitoring with alerts |

## Certifications that match this path
- Linux Foundation LFCS (Linux Foundation Certified System Administrator)
- Red Hat RHCSA, then RHCE (Ansible)
- CompTIA Linux+
- In Russia: Astra Linux and RED OS administrator courses are useful for state and enterprise customers
